# История проекта

Проект начался с желания перенести циферблат DM (ID 1017455), созданный для Amazfit T-Rex 2, на часы KOSPET Tank T3 Ultra 2.

В ходе исследования удалось:

- извлечь оригинальный пакет Zepp;
- подтвердить наличие app.json и app.js;
- определить структуру ресурсов;
- принять решение о создании полноценного open-source SDK.
